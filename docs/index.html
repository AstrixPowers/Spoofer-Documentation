Change of accounts/What to do after ban

In case your account was blocked, or you need to change your account do this:

  1. Use Cleanup.bat, that file is placed in the same folder as the launcher.
  2. Change -sid / -seed to any of the allowed numbers, that isnt equal to the previous one.

Creation and use of .bat file

To use the in-built spoofer you have to create .bat file with parameters of launch.

  1. Create .txt file.
  2. Type the -sid / -seed parameter in the .txt file.
  3. Save .txt file, as .bat file.
  4. Place .bat file in the same folder as launcher.
  5. Run .bat file not as admin.

If you didnt understand the text guide, then you can either read the more in-depth guide, or watch our video-guide.

Spoofing partitions

Why would you spoof partitions

In some games, such as Delta Force, spoofing partitions is required in order to bypass the HWID ban.

Spoofing partitions

HAVING A USB WITH WINDOWS INSTALLATOR IS REQUIRED

  1. Download this file
  2. Run the downloaded file.

    IT WILL BLUESCREEN, OR FREEZE AND THEN BLUESCREEN YOUR PC, DONT WORRY, THATS OK.

  3. After bluescreening boot up from your USB flash drive.
  4. Upon booting up in the windows installator, click Repair your computer in the left bottom corner, or on newer versions of windows select Repair Windows option.
  5. Select "Troubleshoot" in the windows repairment tool.
  6. Click "Command prompt"
  7. Type these commands in the following order into the opened CMD:
diskpart
list volume
  1. Now, find the volume, which has your windows on it and its format type is "NTFS", after finding it type:
select volume *volume number*

Example:

YOU HAVE TO TYPE YOUR VOLUME NUMBER WITHOUT THE * *

  1. Type this command:

  1. Find the volume, INFO row of which has nothing in it, and which has the second biggest size out of them all, its format type should be FAT32

    It is okay for the FAT32 volume to have label and letter assigned to it. It is also okay for the fat32 volume to be non-existent, just skip part 10 and 11 if you do not have one.

    Now type in:

select volume *volume number*

Example:

  1. Now type:

If you do not have one, then type in:
